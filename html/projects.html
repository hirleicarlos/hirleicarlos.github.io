Projeto técnico Open Source Infraestrutura

Docker Development Server

Arquitetura local autoral para projetos PHP, Joomla e Laravel

Ambiente executado com Docker Desktop integrado ao Ubuntu/WSL, projetado para reproduzir cenários reais de hospedagem. O HAProxy centraliza as portas 80 e 443, Apache e Nginx delegam PHP ao mesmo alias PHP-FPM e a execução pode alternar entre PHP 8.3, 8.4 e 8.5 conforme a necessidade de cada cliente ou projeto.

  • Roteamento: HAProxy 3.2 com entrada única em 80/443 e acesso sem portas adicionais na URL
  • Servidores: Apache em *.1.localhost e Nginx direto ao PHP-FPM em *.2.localhost, sem passar pelo Apache
  • PHP alternável: PHP 8.3, PHP 8.4 e PHP 8.5 com php-switch.sh, mantendo versões separadas para atender cenários diferentes
  • Dados e ferramentas: MariaDB 11, MySQL 5.7, PostgreSQL 17, phpMyAdmin, Mailpit e Node.js 20
  • Organização: projetos e repositórios Git mantidos em volumes Linux dentro do WSL
