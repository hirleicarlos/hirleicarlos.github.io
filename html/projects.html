Projeto técnico Open Source Infraestrutura

Docker Development Server

Arquitetura local autoral para projetos PHP e Joomla

Ambiente executado com Docker Desktop integrado ao Ubuntu/WSL, projetado para reproduzir cenários reais de hospedagem. O HAProxy centraliza as portas 80 e 443 e encaminha cada domínio diretamente para servidores Apache ou Nginx independentes, com SSL local e volumes Linux compartilhados.

  • Roteamento: HAProxy 3.2 com entrada única em 80/443 e acesso sem portas adicionais na URL
  • Servidores: Apache em *.1.localhost e Nginx direto ao PHP-FPM em *.2.localhost, sem passar pelo Apache
  • PHP 8.3: GD com WebP, PDO, Intl, ZIP, SOAP, sockets, OPcache e extensões para Joomla
  • Dados e ferramentas: MariaDB 11, PostgreSQL 17, phpMyAdmin e Node.js 20
  • Organização: projetos e repositórios Git mantidos em volumes Linux dentro do WSL
