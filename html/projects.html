Pousada Licor de Caju — Site & Sistema de Reservas

Desenvolvimento e manutenção de site institucional e sistema de reservas para pousada, incluindo motor de reservas, painel administrativo e sistema de balcão para gestão diária.

  • Contexto: Cliente real / Produção
  • Entregas: site público, motor de reservas, painel administrativo
  • Tecnologias: Joomla 4.x, PHP 8.3, MySQL, Bootstrap, jQuery
  • Status: Sistema ativo em produção

Plugin Joomla — Botão Flutuante de WhatsApp

Desenvolvimento de plugin Joomla do tipo System para inclusão de botão flutuante de WhatsApp no site, com configuração via painel administrativo. Projeto criado como extensão reutilizável, versionada e publicada no GitHub.

  • Contexto: Projeto próprio / Open Source
  • Entregas: plugin funcional, instalação via ZIP, parâmetros configuráveis
  • Tecnologias: PHP, Joomla Framework, HTML, CSS, XML
  • Status: Código público com release versionado

SomosCooperativismo — Portal do cooperativismo nacional

Atuação na implementação, migração e evolução do portal institucional do cooperativismo nacional. O trabalho envolveu a transição de plataforma (Laravel para Joomla), atualização de versão (Joomla 4 para Joomla 5), padronização visual e sustentação contínua do sistema.

  • Contexto: Portal público / Ambiente de produção
  • Entregas: instalação e configuração do Joomla, migração de dados e conteúdo, atualização de versão (J4 → J5), ajustes e modernização de layout
  • Atuação: levantamento de requisitos junto ao negócio, desenvolvimento, manutenção e evolução de componentes, módulos e plugins
  • Tecnologias: Joomla 4/5, PHP, jQuery, Bootstrap, Helix Framework, SP Page Builder, Component Creator
  • Status: Sistema ativo em produção

  • Entregas: migração de dados e conteúdo, manutenção evolutiva, criação e customização de componentes, módulos e plugins, suporte técnico e ajustes contínuos

  • Atuação: levantamento de requisitos, desenvolvimento sob demanda, sustentação técnica e evolução do portal
  • Status: Sistema ativo em produção

Central da Marca — Plataforma de materiais institucionais

Evolução e sustentação da Central da Marca, uma plataforma para cooperativas acessarem e baixarem materiais oficiais (marcas, manuais, imagens e campanhas). Funciona como um “quase e-commerce”: catálogo e fluxo de aquisição/disponibilização de conteúdos, porém sem valores e sem pagamento.

  • Contexto: Plataforma de serviços / Acesso controlado
  • Entregas: evolução de interface e estrutura, melhorias de usabilidade, organização do catálogo de materiais e fluxo de acesso
  • Atuação: levantamento de requisitos, manutenção corretiva/evolutiva, criação e manutenção de componentes, módulos e plugins
  • Tecnologias: Joomla, PHP, jQuery, Bootstrap, Helix Framework, SP Page Builder
  • Status: Sistema ativo em produção

Exame Rápido — Site e Sistema de Marcação de Consultas e Exames

  • Tecnologias: PHP, JavaScript, jQuery, HTML, CSS, banco de dados relacional, joomla
  • Status: Sistema ativo em produção
