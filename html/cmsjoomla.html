Como eu organizo extensões

As extensões geralmente seguem padrões de manutenção, estrutura limpa, parametrização administrativa, compatibilidade com templates e, quando possível, documentação e release versionado.

Abordagem: priorizo clareza estrutural, reaproveitamento, segurança, compatibilidade entre versões e facilidade de manutenção para reduzir retrabalho em evolução futura.

Open source Módulo Joomla 4/5/6

Módulo Joomla — HC Mídias Sociais

Módulo de site para exibição personalizada de links de mídias sociais, com suporte a SVG, imagem e classes CSS. Itens configuráveis e repetíveis no admin, com opções de layout e estilo.

  • Contexto: Projeto próprio / Open Source
  • Entregas: itens repetíveis, suporte a SVG/Imagem, modos de layout
  • Tecnologias: Joomla 4/5/6, PHP, XML (params), CSS
  • Status: Código público no GitHub
