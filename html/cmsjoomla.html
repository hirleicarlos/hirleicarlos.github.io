Open Source

Novo Template v1.2.0 Joomla 5/6

Template Joomla — HC Carlix

Template nativo para Joomla 5/6 construído com filosofia Joomla-native first: sem Bootstrap, sem jQuery, sem page builder. CSS puro com custom properties, grid de 12 colunas, JS vanilla, fontes self-hosted e Web Asset Manager nativo.

  • Contexto: Projeto próprio / Open Source · GPL v2+
  • Entregas: overrides progressivos (mod_menu), chromes próprios (card, plain), painel administrativo com parâmetros, layouts component/error/offline
  • Tecnologias: Joomla 5/6, PHP 8.3+, CSS nativo (custom properties), JS vanilla, Web Asset Manager, i18n (pt-BR / en-GB)
  • Status: Em desenvolvimento ativo · Código público no GitHub

JED ↗ Módulo v1.0.0 Joomla 4/5/6

Módulo Joomla — HC IgPulse (Instagram Feed)

Módulo de site para exibir posts e reels do Instagram via Graph API, com cache configurável e 4 layouts responsivos (carousel, grid, mosaic, strip). HTML semântico, sem frameworks externos.

  • Contexto: Projeto próprio / Open Source · GPL v2+
  • Entregas: integração Instagram Graph API, 4 layouts, cache, aspect ratio configurável, lightbox/newtab/instagram
  • Tecnologias: Joomla 4/5/6, PHP 8.3+, Graph API, XML (params), CSS
  • Status: Código público no GitHub · Update server ativo

JED ↗ Plugin System v3.1.0 Joomla 4/5/6

Plugin Joomla — Botão Flutuante de WhatsApp

Plugin do tipo System que injeta um botão flutuante de WhatsApp no frontend sem alterar template. Configuração completa via painel, com overrides para mobile, horário de atendimento por dia da semana e animações.

  • Contexto: Projeto próprio / Open Source · GPL v2+
  • Entregas: overrides mobile, schedule com timezone, animações (slide/bounce/fade), tooltip, controle por menu/dispositivo
  • Tecnologias: PHP 8.3+, Joomla 4/5/6, DI (Service Provider), WebAssetManager, CSS, JS
  • Status: Código público no GitHub · Update server ativo
Ver repositório no GitHub ↗
JED ↗ Módulo v1.0.0 Joomla 4/5/6

Módulo Joomla — HC Mídias Sociais

Módulo de site para exibição personalizada de links de mídias sociais, com suporte a SVG, imagem e classes CSS. Itens repetíveis no admin, 5 layouts (default, minimal, inline, boxed, stacked) e arquitetura Dispatcher + Helper.

  • Contexto: Projeto próprio / Open Source · GPL v2+
  • Entregas: 5 layouts, itens repetíveis, suporte a SVG/Imagem, CSS Variables por item, modos icon/text/both
  • Tecnologias: Joomla 4/5/6, PHP 8.3+, Dispatcher/HelperFactory, XML (params), CSS
  • Status: Código público no GitHub · Update server ativo
