HC Social Media

Links de mídias sociais para Joomla 4, 5 e 6

Um módulo para criar listas de links sociais com itens repetíveis, suporte a SVG, imagens e classes CSS, cinco layouts e personalização visual por item.
Baixar versão 1.0.0 Ver no JED ↗ GitHub ↗

Visão geral

Lista social simples, arquitetura limpa

O HC Social Media organiza links de mídias sociais como um módulo Joomla moderno. A proposta é entregar um componente visual pequeno, mas com separação clara entre parâmetros, normalização, helper, layouts e CSS, mantendo compatibilidade com Joomla 4, 5 e 6.

Problema e público

Links sociais com manutenção previsível

Problema

Evitar listas improvisadas

O módulo concentra links, ícones e aparência no administrador, sem espalhar HTML manual por artigos ou templates.

Público

Sites institucionais e portfólios

Útil para rodapés, cabeçalhos, sidebars, páginas de contato e blocos de assinatura.

Casos de uso

Ícone, texto ou ambos

A extensão cobre desde listas minimalistas até botões visuais com cor e estilo definidos por item.

Recursos reais

O que a versão 1.0.0 entrega

Itens

Campos repetíveis

Permite cadastrar múltiplos links sociais no painel do módulo.

Layouts

Cinco apresentações

default, minimal, inline, boxed e stacked.

Ícones

SVG, imagem ou classe CSS

O item pode usar SVG, imagem ou classes CSS, conforme a necessidade do projeto.

Exibição

Modo visual flexível

Suporte a modos com ícone, texto ou combinação dos dois.

Estilo

CSS variables por item

Personalização de cor e apresentação sem misturar lógica de renderização e estilo.

Segurança

Renderização segura

Camada de normalização e saída controlada para manter o módulo previsível.

Arquitetura

Dependências
