HC Image Optimizer

Conversão automática para WebP no Joomla 5 e Joomla 6

Processe imagens JPG, JPEG e PNG diretamente nos fluxos do Joomla. Defina tamanho e qualidade, preserve proporções, mantenha o original quando necessário e gere variantes para diferentes usos editoriais.
Baixar versão 1.2.2 Ver no JED ↗ GitHub ↗

Visão geral

Otimização dentro do fluxo editorial

O HC Image Optimizer é um pacote formado por dois plugins. O plugin de sistema executa validação, redimensionamento, conversão e geração de perfis. O plugin Media Action integra o processamento aos uploads do Gerenciador de Mídia. A versão 1.2.2 processa tudo localmente com a extensão GD do PHP.

Principais funcionalidades

Conversão

WebP automático

Converte JPG, JPEG e PNG para WebP durante uploads e fluxos compatíveis de salvamento.

Dimensões

Resize proporcional

Limita o maior lado sem cortar, deformar ou ampliar imagens que já estão dentro do limite.

Variantes

Múltiplos perfis

Cria imagem principal e perfis independentes, como thumb, featured e card.

Transparência preservada

Arquivos

Permite manter a imagem de origem e controlar a substituição de referências locais.

Segurança

MIME e caminhos validados

Compara extensão e MIME real, normaliza nomes e restringe o processamento à pasta monitorada.

Fluxo

Como funciona

1 Upload Joomla recebe a imagem.
2 Validação Extensão, MIME e caminho.
3 Dimensões Cálculo pelo maior lado.
4 WebP Imagem principal codificada.
5 Perfis Variantes ativas geradas.
6 Resultado Arquivos, referência e log.

Dúvidas frequentes

FAQ

O plugin amplia imagens pequenas?

Não. Quando a imagem já está dentro do limite configurado, suas dimensões são preservadas.

O plugin corta a imagem?

Não. O redimensionamento mantém a proporção original e não executa crop automático.

Quais formatos de entrada são aceitos?

JPG, JPEG e PNG. A saída da versão 1.2.2 é WebP.

Posso criar mais de dois perfis?

Sim. O Subform permite adicionar vários perfis e o código não define um limite fixo.

A imagem original pode ser mantida?

Sim. Manter o arquivo original é o comportamento padrão.

O processamento usa uma API externa?

Não. A versão atual processa as imagens localmente com a extensão GD do PHP.

Imagick e AVIF são suportados?

Não. A versão 1.2.2 trabalha com a extensão GD do PHP e saída em WebP.
